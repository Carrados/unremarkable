# Flow on unremarkable.me

This file is for Flo, Cloud Dancer's flow agent (`flo/FLO.md`). It lists the shapes of flow this site has: the kinds of thing the owner adds often, each piece on its own, such as a news item or a post. Flo fills these shapes and nothing else. Anything that isn't in a shape here is fabric: layout, sections, design and standing wording, done with the owner there.

Adding a shape is fabric too. When a new one is made, it is written down here: what it is, where each piece goes and what it is called, what it starts with, where it is listed, and how the site is built afterwards.
