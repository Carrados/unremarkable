An accessibility statement is where most sites admit what they couldn't manage. Ours is built to Zero Information Casualty version 1.7, so that nobody, whether reading directly, using assistive technology or sending an agent, loses access to anything published here.

How it is built

  • Every page is plain, static HTML. No content depends on JavaScript, and the site uses none.
  • Each page has one main heading, headings in order, landmark regions and a skip link to the main content.
  • Text sizes are relative, so the site respects your browser's text size and zoom.
  • All text meets WCAG AAA contrast, at least 7:1, in both the light scheme and the dark scheme, which follows your system setting. If your system asks for more contrast, secondary text and dividing lines change to the full text colour.
  • Nothing moves, so there is nothing to switch off for reduced motion.

Standards and testing

The site aims to meet WCAG 2.2 at level AA as a baseline, alongside Zero Information Casualty v1.7, and is tested with a screen reader as it changes.

This is a statement of how the site is built and what it aims for, not a claim of certified conformance. No independent audit has been carried out.

For agents

Agents acting for a person are welcome on every public page. There is a summary for agents at llms.txt, the full text of the site in one file at llms-full.txt, and a Markdown version of every page alongside it. All of them are generated from the pages you are reading when the site is built, not maintained by hand.

The site's permissions for search indexing and model training are declared separately in its robots.txt file.
